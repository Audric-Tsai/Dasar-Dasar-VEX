# 01 — Structure

The robot's frame. Everything else bolts onto this.

The first thing to understand: **almost every part here comes in two versions —
aluminium and steel.** Same shape, same hole pattern, different material. Steel is
far stiffer but far heavier.

---

## C-Channel & U-Channel — Aluminium

| Part | Code |
|---|---|
| 1x2x1x25 Aluminum C-Channel | `276-2288` |
| 1x2x1x35 Aluminum C-Channel | `276-2289` |
| 1x3x1x35 Aluminum C-Channel | `276-4359` |
| 1x5x1x25 Aluminum C-Channel | `276-2290` |
| 1x5x1x35 Aluminum C-Channel | `276-2298` |
| 2x2x2x20 Aluminum U-Channel | `276-7285` |

**Read the name.** `1x5x1x35` = 1 hole on one side, 5 holes across the middle,
1 hole on the other side, 35 holes long. The last number is always the length.

**Why the C shape.** A folded bar resists bending far better than a flat plate of
the same aluminium weight. The upright sides are what carry the load.

**U-channel** has two taller sides. Stiffer still, but heavier and it takes up
more room.

**The holes are square, not round.** This confuses beginners more than anything
else. The explanation is in folder 02, under Bearing Flat.

---

## Angle, Bar, Plate — Aluminium

| Part | Code |
|---|---|
| 1x1x35 Aluminum Angle | `276-6484` |
| 2x2x35 Aluminum Angle | `276-2304` |
| 1x25 Aluminum Bar | `276-2307` |
| 5x25 Aluminum Plate | `276-2311` |
| 15 x 30 Base Plate | `276-1341` |

**Angle** is L-shaped. Lighter than C-channel but weaker. Use it for corner joints
and anywhere that isn't carrying serious load.

**Bar** and **Plate** are flat. Weakest of the three. Easy to bend to whatever
shape you need. Good for covers and links, not for the main frame.

**The 15x30 Base Plate** is a large plate for the base of the robot.

---

| 3x3x35 Steel Angle | `275-1144` |

| 2x1x35 Steel Chassis Rail | `275-1146` |
| 1 x 25 Steel Bar | `275-1141` |
| 5x15 Steel Plate | `275-2023` |
| 5x25 Steel Plate | `275-1140` |

**When to use steel.** Only where you genuinely need stiffness — usually the lower
drivetrain frame. Steel makes the robot heavy, and weight makes the motors work
harder and drains the battery faster.

**Chassis Rail** only comes in steel. Its shape is designed specifically for
drivetrain frames.

---

## Gussets

Small angled plates that reinforce joints. If your frame flexes at the corners,
this is what you need.

**The angle system** — every angle comes in a flat and a bent version:

| Angle | Flat | Bent |
|---|---|---|
| 30° | `276-7758-001` | `276-7758-002` |
| 45° | `276-7759-001` | `276-7759-002` |
| 60° | `276-7760-001` | `276-7760-002` |
| 90° | `276-7761-001` | `276-7761-002` |

**Flat** joins two parts lying in the same plane. **Bent** joins two parts in
different planes.

**Other gussets:**

| Part | Code |
|---|---|
| 45-Degree Gusset | `275-1186` |
| Plus Gusset | `276-1110-001` |
| 90-Degree Gusset | `276-1110-002` |
| Angle Gusset | `276-1110-003` |
| C-Channel Coupler Gusset | `276-2575` |
| Angle Corner Gusset | `276-2576` |
| 90-Degree Gusset Angle | `276-2577-001` |
| 90-Degree Gusset Plate | `276-2577-002` |
| Angle Coupler Gusset | `276-2578` |

**Coupler gussets** exist specifically to join two C-channels into one longer bar.

---

## Standoffs

Round rods threaded at both ends. They create a gap between two parts of the robot.

| Length | Code |
|---|---|
| 1/2" | `275-1014` |
| 3/4" | `275-1015` |
| 1.00" | `275-1016` |
| 1.50" | `275-1017` |
| 2.00" | `275-1018` |
| 2.50" | `275-1019` |
| 3.00" | `275-1020` |
| 4.00" | `275-1021` |
| 5.00" | `275-1022` |
| 6.00" | `275-1023` |

**Don't underestimate these.** Two plates joined by standoffs are far stiffer than
one plate on its own. Standoffs are often the lightest way to stiffen a frame
without adding more C-channel.

---

## Common Mistakes

**Using steel everywhere.** The robot ends up heavy, slow, and hard on the
battery. Steel only where you actually need it.

**Using plate for the main frame.** Plate is the weakest option. Frames get
C-channel.

**Misreading C-channel sizes.** The last number is the length, not the width.

**Forgetting gussets at the corners.** A square frame without gussets turns into a
parallelogram the first time it takes a hit.

# 01 — Struktur

Rangka robot. Semua part lain nempel ke sini.

Yang harus kamu sadari duluan: **ada dua versi dari hampir semua part di sini —
aluminium dan baja.** Bentuk dan lubangnya sama, yang beda cuma bahan. Baja jauh
lebih kaku tapi jauh lebih berat.

## C-Channel & U-Channel — Aluminium

| Part | Kode |
|---|---|
| 1x2x1x25 Aluminum C-Channel | `276-2288` |
| 1x2x1x35 Aluminum C-Channel | `276-2289` |
| 1x3x1x35 Aluminum C-Channel | `276-4359` |
| 1x5x1x25 Aluminum C-Channel | `276-2290` |
| 1x5x1x35 Aluminum C-Channel | `276-2298` |
| 2x2x2x20 Aluminum U-Channel | `276-7285` |

**Kenapa bentuk C.** Batang yang dilipat jauh lebih kuat nahan bengkok daripada
pelat rata dengan berat aluminium yang sama. Sisi yang berdiri itu yang nahan
beban.

**U-channel** punya dua sisi yang lebih tinggi. Lebih kaku lagi, tapi lebih berat
dan lebih makan ruang.

**Lubangnya kotak, bukan bulat.** Ini yang paling bikin bingung pemula.

## Yang Sering Salah

**Pakai baja di mana-mana.** Robot jadi berat, lambat, dan boros baterai. Baja
cuma di tempat yang beneran butuh.

**Pakai plate buat rangka utama.** Plate itu paling lemah. Rangka pakai
C-channel.

**Salah baca ukuran C-channel.** Angka terakhir itu panjang, bukan lebar.

**Lupa gusset di sudut.** Rangka kotak tanpa gusset bisa jadi jajar genjang pas
kena benturan.

# 01 — 结构件

机器人的骨架。其他所有零件都装在它上面。

首先要明白一件事：**这里几乎每个零件都有两个版本 —— 铝制和钢制。** 形状一样，
孔位一样，只有材料不同。钢的刚性强得多，但也重得多。

---

## C 型槽和 U 型槽 —— 铝制

| 零件 | 编号 |
|---|---|
| 1x2x1x25 Aluminum C-Channel | `276-2288` |
| 1x2x1x35 Aluminum C-Channel | `276-2289` |
| 1x3x1x35 Aluminum C-Channel | `276-4359` |
| 1x5x1x25 Aluminum C-Channel | `276-2290` |
| 1x5x1x35 Aluminum C-Channel | `276-2298` |
| 2x2x2x20 Aluminum U-Channel | `276-7285` |

**看懂名字。** `1x5x1x35` = 一边 1 个孔，中间 5 个孔，另一边 1 个孔，长度 35 个孔。
最后一个数字永远是长度。

**为什么做成 C 形。** 同样重量的铝，折起来的型材比平板抗弯能力强得多。
立起来的两边才是真正承力的部分。

**U 型槽** 两边更高，刚性更好，但更重也更占空间。

**孔是方的，不是圆的。** 这是新手最容易困惑的地方。
解释在 02 文件夹的 Bearing Flat 部分。

---

## 角铁、条板、平板 —— 铝制

| 零件 | 编号 |
|---|---|
| 1x1x35 Aluminum Angle | `276-6484` |
| 2x2x35 Aluminum Angle | `276-2304` |
| 1x25 Aluminum Bar | `276-2307` |
| 5x25 Aluminum Plate | `276-2311` |
| 15 x 30 Base Plate | `276-1341` |

**Angle（角铁）** 是 L 形。比 C 型槽轻，但也更弱。用在转角连接和不承重的地方。

**Bar（条板）** 和 **Plate（平板）** 是平的，三者中最弱。可以按需要弯成任意形状。
适合做盖板和连接件，不要拿来做主骨架。

**15x30 Base Plate** 是一块大平板，用作机器人的底板。

---

## 钢制结构件

| 零件 | 编号 |
|---|---|
| 1x2x1x35 Steel C-Channel | `276-2906` |
| 1x5x1x25 Steel C-Channel | `275-1138` |
| 1x5x1x35 Steel C-Channel | `275-1139` |
| 2x2x25 Steel Angle | `275-1142` |
| 2x2x35 Steel Angle | `275-1143` |
| 3x3x35 Steel Angle | `275-1144` |
| 2x1x25 Steel Chassis Rail | `275-1145` |
| 2x1x35 Steel Chassis Rail | `275-1146` |
| 1 x 25 Steel Bar | `275-1141` |
| 5x15 Steel Plate | `275-2023` |
| 5x25 Steel Plate | `275-1140` |

**什么时候用钢。** 只用在真正需要刚性的地方 —— 通常是底盘下方的骨架。
钢会让机器人变重，重量会让电机更吃力，电池也掉得更快。

**Chassis Rail（底盘导轨）** 只有钢制版本。它的形状是专门为底盘骨架设计的。

## 加强板（Gusset）

带角度的小铁片，用来加固接头。如果你的骨架在转角处晃动，就需要它。

**角度系列** —— 每个角度都有平的（flat）和折弯的（bent）两种：

| 角度 | Flat（平） | Bent（折弯） |
|---|---|---|
| 30° | `276-7758-001` | `276-7758-002` |
| 45° | `276-7759-001` | `276-7759-002` |
| 60° | `276-7760-001` | `276-7760-002` |
| 90° | `276-7761-001` | `276-7761-002` |

**Flat** 用来连接同一平面上的两个零件。**Bent** 用来连接不同平面上的两个零件。

**其他加强板：**

| 零件 | 编号 |
|---|---|
| 45-Degree Gusset | `275-1186` |
| Plus Gusset | `276-1110-001` |
| 90-Degree Gusset | `276-1110-002` |
| Angle Gusset | `276-1110-003` |
| C-Channel Coupler Gusset | `276-2575` |
| Angle Corner Gusset | `276-2576` |
| 90-Degree Gusset Angle | `276-2577-001` |
| 90-Degree Gusset Plate | `276-2577-002` |
| Angle Coupler Gusset | `276-2578` |

**Coupler gusset（连接加强板）** 是专门用来把两根 C 型槽接成一根长条的。

## 支撑柱（Standoff）

两端带螺纹的圆杆，用来在机器人两个部分之间撑出间距。

| 长度 | 编号 |
|---|---|
| 1/2" | `275-1014` |
| 3/4" | `275-1015` |
| 1.00" | `275-1016` |
| 1.50" | `275-1017` |
| 2.00" | `275-1018` |
| 2.50" | `275-1019` |
| 3.00" | `275-1020` |
| 4.00" | `275-1021` |
| 5.00" | `275-1022` |
| 6.00" | `275-1023` |

**别小看它。** 用支撑柱连起来的两块板，比单独一块板刚性强得多。
支撑柱常常是在不增加 C 型槽的前提下，让骨架变硬的最轻办法。

---

## 常见错误

**到处用钢。** 机器人变重、变慢、费电。钢只用在真正需要的地方。

**拿平板做主骨架。** 平板是最弱的。骨架要用 C 型槽。

**看错 C 型槽尺寸。** 最后一个数字是长度，不是宽度。

**转角忘了加强板。** 没有加强板的方形骨架，第一次被撞就会歪成平行四边形。
