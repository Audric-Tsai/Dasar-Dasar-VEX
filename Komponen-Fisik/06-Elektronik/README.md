# 06 — Electronics

The robot's brain and power.

---

## V5 Core

| Part | Code |
|---|---|
| V5 Robot Brain | `276-4810` |
| V5 Robot Battery Li-Ion 1100mAh | `276-4811` |
| V5 Battery Clip | `276-6020` |
| V5 Power Cable Assortment | `276-4817` |
| V5 Controller | `276-4820` |
| V5 Robot Radio | `276-4831` |

**Brain** — the robot's computer. 21 smart ports, a touchscreen, 8 program slots.
Every line of code you write runs here.

**Battery** — Li-Ion 1100mAh. Watch the indicator. A robot on under 50% battery
moves differently from one on full, and a time-based autonomous will miss.

**Battery Clip** holds the battery so it can't come loose in a collision. Cheap,
frequently forgotten, and a battery falling out mid-match means the robot is
completely dead.

**Controller** — two joysticks, eight buttons, a small screen.

**Radio** — Brain-to-controller communication.

---

## Motors & Cartridges

| Part | Code |
|---|---|
| V5 Smart Motor (11W) | `276-4840` |
| Smart Motor (5.5W) | `276-4842` |
| Smart Motor 36:1 Cartridge (100 RPM) | `276-5840` |
| Smart Motor 18:1 Cartridge (200 RPM) | `276-5841` |
| Smart Motor 6:1 Cartridge (600 RPM) | `276-5842` |
| Smart Motor Cap Replacement | `276-6780` |
| Smart Motor #8-32 Threaded Inserts | `276-6781` |

**The 11W motor** — the main one. Inside it there's already an encoder counting
position, a temperature sensor, and current measurement. That's why you can write
accurate autonomous without buying extra sensors.

**The 5.5W motor** — the small version. For light mechanisms in tight spaces.

### Cartridges

Swappable gears inside the motor. This is what sets the motor's character.

| Colour | Ratio | Speed | Character | Code |
|---|---|---|---|---|
| Red | 36:1 | 100 RPM | Strongest, slowest | `276-5840` |
| Green | 18:1 | 200 RPM | Standard | `276-5841` |
| Blue | 6:1 | 600 RPM | Fastest, weakest | `276-5842` |

**Cartridges are a separate SKU.** A motor ships with one cartridge; if you need a
different one, buy it separately.

**Blue cartridge straight to the wheels is a trap.** 600 RPM is too fast for a
drivetrain — the robot is hard to control and the wheels slip. Competitive teams
almost always gear it back down externally.

**Cap Replacement** and **Threaded Inserts** are service parts. Cracked motor caps
and stripped threads are normal after a few seasons.

**Smart Cables** connect motors and sensors to the Brain. They're reversible, so
there's no wrong end.

**Cable Stock + Connectors** let you make custom lengths. If you're constantly
too long or too short, this is the fix.

**3-Wire Expander** adds more 3-wire ports when the Brain runs out.

**Retaining Clips** hold cables so vibration can't pull them out. If a motor
suddenly stops being detected, **the cable is the first suspect, before the code.**

---

## Common Mistakes

**Blaming the code when the cable is loose.** Check cables first, always.

**Forgetting the battery clip.** Battery falls out = robot completely dead
mid-match.

**Blue cartridge straight to the wheels.** The robot bolts off and can't be
controlled.

**Not tidying cables.** They wrap around a wheel, get yanked, motor dies. Zip ties
are cheap — see folder 10.

# 06 — Elektronik

Otak dan tenaga robot.

## V5 Inti

| Part | Kode |
|---|---|

**Brain** — komputer robot. 21 port smart, layar sentuh, 8 slot program. Semua
kode yang kamu tulis jalannya di sini.

**Battery** — Li-Ion 1100mAh. Perhatiin indikatornya. Robot dengan baterai di
bawah 50% gerakannya beda dari yang penuh, dan autonomous berbasis waktu bakal
meleset.

**Battery Clip** nahan baterai biar nggak lepas pas kena benturan. Murah, sering
dilupain, dan baterai copot di tengah match artinya robot mati total.

**Controller** — dua joystick, delapan tombol, layar kecil.

**Radio** — komunikasi Brain ke controller.

## Motor & Cartridge

| Part | Kode |
|---|---|
| V5 Smart Motor (11W) | `276-4840` |
| Smart Motor (5.5W) | `276-4842` |
| Smart Motor 36:1 Cartridge (100 RPM) | `276-5840` |
| Smart Motor 18:1 Cartridge (200 RPM) | `276-5841` |
| Smart Motor 6:1 Cartridge (600 RPM) | `276-5842` |
| Smart Motor Cap Replacement | `276-6780` |
| Smart Motor #8-32 Threaded Inserts | `276-6781` |

**Motor 11W** — motor utama. Di dalamnya sudah ada encoder yang ngitung posisi,
sensor suhu, dan pengukur arus. Ini alasan kamu bisa bikin autonomous akurat
tanpa beli sensor tambahan.

**Motor 5.5W** — versi kecil. Buat mekanisme ringan di tempat sempit.

### Cartridge

Gir yang bisa diganti di dalam motor. Ini yang nentuin karakter motornya.

| Warna | Rasio | Kecepatan | Sifat | Kode |
|---|---|---|---|---|
| Merah | 36:1 | 100 RPM | Paling kuat, paling pelan | `276-5840` |
| Hijau | 18:1 | 200 RPM | Standar | `276-5841` |
| Biru | 6:1 | 600 RPM | Paling cepat, paling lemah | `276-5842` |

**Cartridge itu SKU terpisah.** Motor dijual sama satu cartridge; kalau kamu
butuh yang lain, beli sendiri.

**Cartridge biru langsung ke roda itu jebakan.** 600 RPM terlalu cepat buat
drivetrain — robot susah dikontrol dan roda selip. Tim kompetitif hampir selalu
nurunin lagi pakai gear luar.

**Cap Replacement** dan **Threaded Insert** itu part servis. Tutup motor retak
dan ulir slek itu kejadian biasa setelah beberapa musim.

## Yang Sering Salah

**Nyalahin kode padahal kabelnya lepas.** Cek kabel dulu, selalu.

**Lupa battery clip.** Baterai copot = robot mati total di tengah match.

**Cartridge biru langsung ke roda.** Robot lari kenceng dan nggak bisa
dikontrol.

**Kabel nggak dirapiin.** Kelilit roda, ketarik, motor mati. Zip tie itu murah —
lihat folder 10.

# 06 — 电子元件

机器人的大脑和动力。

---

## V5 核心部件

| 零件 | 编号 |
|---|---|
| V5 Robot Brain | `276-4810` |
| V5 Robot Battery Li-Ion 1100mAh | `276-4811` |
| V5 Battery Clip | `276-6020` |
| V5 Power Cable Assortment | `276-4817` |
| V5 Controller | `276-4820` |
| V5 Robot Radio | `276-4831` |

**Brain（主控）** —— 机器人的电脑。21 个智能端口、触摸屏、8 个程序槽。
你写的每一行代码都在这里运行。

**Battery（电池）** —— 锂电 1100mAh。注意看电量指示。
电量低于 50% 的机器人，动作和满电时不一样，基于时间的自动程序会跑偏。

**Battery Clip（电池卡扣）** 把电池固定住，撞击时不会松脱。
便宜，经常被忽略，而比赛中途电池掉出来意味着机器人彻底停摆。

**Controller（手柄）** —— 两个摇杆、八个按键、一块小屏幕。

**Radio（无线模块）** —— 主控和手柄之间的通信。

---

## 电机和齿轮盒

| 零件 | 编号 |
|---|---|
| V5 Smart Motor (11W) | `276-4840` |
| Smart Motor (5.5W) | `276-4842` |
| Smart Motor 36:1 Cartridge (100 RPM) | `276-5840` |
| Smart Motor 18:1 Cartridge (200 RPM) | `276-5841` |
| Smart Motor 6:1 Cartridge (600 RPM) | `276-5842` |
| Smart Motor Cap Replacement | `276-6780` |
| Smart Motor #8-32 Threaded Inserts | `276-6781` |

**11W 电机** —— 主力电机。内部已经集成了记录位置的编码器、温度传感器和电流检测。
这就是为什么你不用额外买传感器也能写出精准的自动程序。

**5.5W 电机** —— 小型版本。用于空间紧张处的轻负载机构。

### 齿轮盒（Cartridge）

电机内部可更换的齿轮组。它决定了这个电机的性格。

| 颜色 | 减速比 | 转速 | 特性 | 编号 |
|---|---|---|---|---|
| 红 | 36:1 | 100 RPM | 最有力，最慢 | `276-5840` |
| 绿 | 18:1 | 200 RPM | 标准 | `276-5841` |
| 蓝 | 6:1 | 600 RPM | 最快，最没劲 | `276-5842` |

**齿轮盒是单独的货号。** 电机出厂自带一个齿轮盒；需要别的要另外买。

**蓝色齿轮盒直接接轮子是个坑。** 600 RPM 对底盘来说太快了 ——
机器人难控制，轮子还打滑。竞技队伍几乎都会再用外部齿轮减速一次。

**Cap Replacement（电机盖）** 和 **Threaded Inserts（螺纹嵌件）** 是维修件。
用了几个赛季之后，电机盖开裂和螺纹拧滑都是常事。

如果某个电机突然识别不到了，**先怀疑线，再怀疑代码。**

## 常见错误

**线松了却去怪代码。** 永远先查线。

**忘装电池卡扣。** 电池掉出来 = 比赛中途机器人彻底停摆。

**蓝色齿轮盒直接接轮子。** 机器人窜出去，根本控制不住。

**线不整理。** 缠进轮子里、被拽掉，电机就废了。扎带很便宜 —— 见 10 文件夹。
