# 09 — Mechanisms

Ready-made parts for motion more complicated than plain rotation. You could build
these yourself from C-channel and gears, but these are already designed and ready
to bolt on.

---

## Linear Motion

For straight-line movement — lifts, extensions, slides.

| Part | Code |
|---|---|
| Linear Slide Track | `276-1926-001` |
| Longer Linear Slide Track | `276-1926-005` |
| Linear Slide Bracket | `276-1926-002` |
| Inner Slide Truck | `276-1926-003` |
| Outer Slide Truck | `276-1926-004` |
| Inner Slide Truck | `276-6465-001` |
| Outer Slide Truck | `276-6465-002` |
| Linear Motion Additional Truck Kit | `276-4489` |

**Track** is the rail, **truck** is the thing that runs along it.

**Inner and outer** are used together to build a staged lift — the inner track
slides along the outer track, so the lift can extend beyond the robot's own frame.
This is the basis of a cascade lift.

---

## Turntables

| Part | Code |
|---|---|
| Large Turntable Bearing Assembly | `276-1810-001` |
| Small Turntable Bearing Assembly | `276-1810-005` |
| Large Turntable Bearing V2 Assembly | `276-5652-000` |
| Small Turntable Bearing V2 Assembly | `276-5652-004` |
| Turntable Mounting Bracket | `276-5652-007` |

A large ring-shaped bearing. For a section of the robot that rotates on top of
another section — for example an arm that can swing 360° above the drivetrain.

**Get the V2** if you're buying new.

---

## Advanced Mechanics and Motion Kit

| Part | Code |
|---|---|
| Advanced Mechanics and Motion Kit | `276-2045` |
| Hand Crank | `276-2045-001` |
| Lead Screw | `276-2045-032` |

| Lead Screw Bracket | `276-2045-033` |
| Drop Off Cam | `276-2045-061` |
| Cam Follower | `276-2045-066` |
| Cam Follower Bracket | `276-2045-064` |
| U-Joint | `276-2045-020` |
| 16t Bevel Gear | `276-2045-051` |
| 32t Bevel Gear | `276-2045-052` |

**Lead Screw** converts rotation into slow, very powerful straight-line motion. It
can't be back-driven from the output side, so it holds a load without the motor
running.

**Cams** convert rotation into repeated up-and-down movement.

**U-Joints** transmit rotation between two shafts that aren't in line.

---

## Ready-Made Kits

| Part | Code |
|---|---|
| Claw Kit | `276-2212` |
| Claw Kit v2 | `276-6010` |
| Winch and Pulley Kit | `276-1546` |
| Intake Roller | `276-1499` |
| Intake Roller | `276-2026` |
| Hinge | `275-1272` |
| V5 Flywheel Weight | `276-8794` |

**Claw Kit** is a ready-made gripper. **Get the v2.**

**Winch and Pulley Kit** for pulling with cable. Useful for lifts that have to stay
light.

**Flywheel Weight** adds mass to a launching mechanism. A heavier wheel stores more
energy, so shots stay consistent even when the motor momentarily drops.

---

## Common Mistakes

**Buying a kit when you could build it.** Kits are expensive and heavy. For
learning, building it yourself from C-channel teaches more.

**Mixing inner and outer trucks from different series.** `276-1926-xxx` and
`276-6465-xxx` are two different series.

**Using a V1 turntable when V2 exists.** V2 is smoother and lasts longer.

# 09 — Mekanisme

Part jadi buat gerakan yang lebih rumit dari sekadar muter. Kamu bisa bikin
sendiri dari C-channel dan gear, tapi ini udah dirancang dan tinggal pasang.

---

## Linear Motion

Buat gerakan lurus — lift, extension, slide.

| Part | Kode |
|---|---|
| Linear Slide Track | `276-1926-001` |
| Longer Linear Slide Track | `276-1926-005` |
| Linear Slide Bracket | `276-1926-002` |
| Inner Slide Truck | `276-1926-003` |
| Outer Slide Truck | `276-1926-004` |
| Inner Slide Truck | `276-6465-001` |
| Outer Slide Truck | `276-6465-002` |
| Linear Motion Additional Truck Kit | `276-4489` |

**Track** itu relnya, **truck** itu yang jalan di atas rel.

**Inner dan outer** dipakai bareng buat bikin lift bertingkat — track dalam geser
di track luar, jadi lift bisa lebih panjang dari rangka robotnya. Ini dasar dari
cascade lift.

Bearing besar berbentuk cincin. Buat bagian robot yang muter di atas bagian lain

bikin sendiri dari C-channel lebih ngajarin.

itu dua seri berbeda.

**Pakai turntable V1 padahal V2 ada.** V2 lebih halus dan lebih awet.

# 09 — 机构件

用于比单纯转动更复杂的动作的成品零件。这些你都可以用 C 型槽和齿轮自己搭，
但这些是已经设计好、装上就能用的。

---

## 直线运动

用于直线动作 —— 举升、伸缩、滑动。

| 零件 | 编号 |
|---|---|
| Linear Slide Track | `276-1926-001` |
| Longer Linear Slide Track | `276-1926-005` |
| Linear Slide Bracket | `276-1926-002` |
| Inner Slide Truck | `276-1926-003` |
| Outer Slide Truck | `276-1926-004` |
| Inner Slide Truck | `276-6465-001` |
| Outer Slide Truck | `276-6465-002` |
| Linear Motion Additional Truck Kit | `276-4489` |

**Track** 是导轨，**truck** 是在导轨上跑的滑块。

**Inner 和 outer** 要配合使用来做多级举升 —— 内层导轨在外层导轨上滑动，
这样举升机构能伸出机器人骨架之外。这就是级联式举升的基础。

---

## 转盘（Turntable）

| 零件 | 编号 |
|---|---|
| Large Turntable Bearing Assembly | `276-1810-001` |
| Small Turntable Bearing Assembly | `276-1810-005` |
| Large Turntable Bearing V2 Assembly | `276-5652-000` |
| Small Turntable Bearing V2 Assembly | `276-5652-004` |
| Turntable Mounting Bracket | `276-5652-007` |

一个大的环形轴承。用于机器人某个部分在另一个部分上方转动 ——
比如可以在底盘上方 360° 回转的机械臂。

新买的话 **选 V2**。

---

## Advanced Mechanics and Motion Kit

| 零件 | 编号 |
|---|---|
| Advanced Mechanics and Motion Kit | `276-2045` |
| Hand Crank | `276-2045-001` |
| Lead Screw | `276-2045-032` |
| Lead Screw Nut | `276-2045-031` |
| Lead Screw Bracket | `276-2045-033` |
| Drop Off Cam | `276-2045-061` |
| Cam Follower | `276-2045-066` |
| Cam Follower Bracket | `276-2045-064` |
| U-Joint | `276-2045-020` |
| 16t Bevel Gear | `276-2045-051` |
| 32t Bevel Gear | `276-2045-052` |

**Lead Screw（丝杆）** 把转动变成缓慢而极其有力的直线运动。
它不能从输出端反向驱动，所以能在电机不通电的情况下托住负载。

**Cam（凸轮）** 把转动变成反复的上下运动。

**U-Joint（万向节）** 在两根不同轴线的传动轴之间传递转动。

---

## 成品套件

| 零件 | 编号 |
|---|---|
| Claw Kit | `276-2212` |
| Claw Kit v2 | `276-6010` |
| Winch and Pulley Kit | `276-1546` |
| Intake Roller | `276-1499` |
| Intake Roller | `276-2026` |
| Hinge | `275-1272` |
| V5 Flywheel Weight | `276-8794` |

**Claw Kit（夹爪套件）** 是现成的夹持机构。**买 v2。**

**Winch and Pulley Kit（绞盘和滑轮套件）** 用绳索拉动。
适合必须做得很轻的举升机构。

**Flywheel Weight（飞轮配重）** 给发射机构增加质量。
更重的轮子储存更多能量，即使电机瞬间掉速，发射也能保持稳定。

---

## 常见错误

**明明能自己搭却去买套件。** 套件又贵又重。
如果是为了学习，用 C 型槽自己搭收获更大。

**混用不同系列的内外滑块。** `276-1926-xxx` 和 `276-6465-xxx` 是两个不同系列。

**有 V2 却还在用 V1 转盘。** V2 更顺滑也更耐用。
